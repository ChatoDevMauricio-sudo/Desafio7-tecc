# Exercício 11 — Classe CalculadoraGeometrica

Formulário para escolher figura (quadrado, retângulo ou círculo), inserir as
medidas e calcular a área.

- Quadrado: lado²
- Retângulo: base × altura
- Círculo: π × raio²

A classe retorna o tipo da figura e o valor da área com 2 casas decimais.

## Como executar
```
php -S localhost:8000
```
