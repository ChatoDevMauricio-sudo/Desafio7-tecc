# Exercício 7 — Classe Viagem

Formulário com origem, destino, distância (km), tempo estimado (horas) e tipo de
veículo (com consumo e preço do combustível).

A classe `Viagem` calcula:
- Velocidade média
- Consumo estimado de combustível
- Custo total da viagem

## Como executar
```
php -S localhost:8000
```
