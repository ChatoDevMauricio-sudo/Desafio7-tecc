# Exercício 4 — Classe Carro

Formulário com modelo, combustível (etanol/gasolina), tanque cheio (litros), consumo (km/l) e km já rodados.

A classe `Carro` calcula:
- Autonomia (km)
- Custo por km (com base no preço do combustível)
- Se é hora da revisão (intervalo de 10.000 km)

## Como executar
```
php -S localhost:8000
```
