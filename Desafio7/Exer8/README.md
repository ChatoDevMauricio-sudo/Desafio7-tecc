# Exercício 8 — Classe CalculadoraFinanceira

Formulário com valor da compra, número de parcelas e taxa de juros mensal.

A classe `CalculadoraFinanceira` calcula:
- Valor de cada parcela com juros compostos (`valor * (1 + juro) ^ n`)
- Total a pagar
- Juros pagos (diferença entre o total e o valor original)

## Como executar
```
php -S localhost:8000
```
