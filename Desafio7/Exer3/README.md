# Exercício 3 — Classe Pedido

Formulário com nome do produto, quantidade, preço unitário e tipo de cliente (normal/premium).

A classe `Pedido` calcula:
- Total bruto (quantidade × preço unitário)
- Desconto de 10% para clientes premium
- Imposto simples de 8% sobre o subtotal
- Total final

## Como executar
```
php -S localhost:8000
```
