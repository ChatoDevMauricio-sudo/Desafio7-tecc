# Exercício 6 — Classe ConversorMoeda

Formulário para digitar valor em reais, escolher moeda destino (USD ou EUR) e
informar a cotação atual.

A classe `ConversorMoeda` calcula o valor convertido com base na cotação informada
manualmente (simulando uma cotação de API).

## Como executar
```
php -S localhost:8000
```
