# Exercício 10 — Classe ReservaHotel

Formulário com nome do hóspede, número de noites e tipo de quarto
(simples R$120, luxo R$200, suíte R$350).

A classe `ReservaHotel` calcula o valor total da hospedagem, aplica 15% de
desconto para estadias acima de 5 noites e exibe mensagem de boas-vindas com
o valor final.

## Como executar
```
php -S localhost:8000
```
