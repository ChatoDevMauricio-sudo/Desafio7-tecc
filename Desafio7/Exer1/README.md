# Exercício 1 — Classe Funcionario

Formulário onde o usuário informa nome, cargo, salário e carga horária semanal.

A classe `Funcionario` calcula:
- Nome completo e cargo (resumo)
- Salário bruto
- Valor da hora trabalhada
- Hora extra (com adicional de 50%)
- Salário final com bônus e horas extras

## Como executar
```
php -S localhost:8000
```
Acesse `http://localhost:8000` no navegador.
