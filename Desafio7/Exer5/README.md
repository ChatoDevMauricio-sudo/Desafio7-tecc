# Exercício 5 — Classe Produto (Controle de Estoque)

Formulário com nome, quantidade em estoque e valor unitário, permitindo simular:
- Entrada no estoque
- Saída do estoque (com checagem de saldo)
- Consulta de valor total em estoque

> Observação: como o PHP é stateless por requisição, cada submissão do formulário
> simula uma movimentação a partir da quantidade informada como estoque atual.

## Como executar
```
php -S localhost:8000
```
